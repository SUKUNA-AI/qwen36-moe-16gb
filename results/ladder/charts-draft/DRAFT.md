# Черновик графиков лесенки main128 — СИНТЕТИКА

Отрисовано по синтетической фикстуре, не по прогонам лесенки. Не результат, не публиковать.
Финальные графики пишутся в `results/ladder/charts/` из `results/ladder/summary.json`:

    python3 tools/ladder-charts.py

Фикстура: СИНТЕТИКА: собрано из замеров разных сессий с разной нагрузкой (f1 soak, S2 soak, S3/S4 A/B, nsys). Не результат лесенки и не публикуется. Только для черновиков графиков.
