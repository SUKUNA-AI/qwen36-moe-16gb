Что дальше

  • Установка main128 вместо f1 с откатом в один шаг — после OK владельца.
  • Nsight Compute не снялся: захват CUDA-графов под ncu висит. Нужно профилировать ядра из компонентных бенчей.
  • D3b с приоритетным потоком (код готов, по умолчанию выключен) — следующий кандидат.
  • Освобождать кэш аллокатора после самопроверок ядер S3: вернёт ~8 слотов.
  • Клиентский map-reduce для документов больше окна, куски по ~100K.
